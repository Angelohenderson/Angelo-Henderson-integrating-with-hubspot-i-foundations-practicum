**Overview**

This project is a web application made with Node.js which integrates with the Hubspot CRM API to display and create records in a custom car brands object. Users are able to see details of car brands. The details include: Model, Company, Fastest car model, and the top speed in mph. It also includes a link to a form to add cars to the CRM and saves it in its memory.

Features:
- Gets and list car brands in  Hubspot
- Creates new records within the Hubspot CRM
- Custom Object integration
- Uses Pug to show dynamic pages to render the applicaton
- Store APU credentials Securely and moves information between the app and the CRM

Technologies Used:
- Node.js — JavaScript runtime
- Express — Web application framework.
- An HTTP request to the HubSpot API.An Axios request to HubSpot API.
- Pug is a server side page templating system.
- dotenv allows you to load environment variables from a file.dotenv - Environment variable configuration from file.
- The HubSpot CRM API allows you to retrieve and create your custom object data.The HubSpot CRM API lets you retrieve and create custom object information.
